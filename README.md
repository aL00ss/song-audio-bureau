# song-audio-bureau

Version de bureau (Windows, macOS, Linux) du studio de musique
[song-audio](https://github.com/aL00ss/song-audio) : la même interface, construite avec Tauri,
et un moteur sonore en Rust qui lit depuis le disque des banques de sons professionnelles
gratuites (plusieurs Go), avec synthétiseurs et effets intégrés.

La version web reste en ligne : https://al00ss.github.io/song-audio/
